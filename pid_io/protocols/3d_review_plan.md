# 3D 모델 반영 · 3D 리뷰 계획 (아이디어, 2026-11-26 - 사용자와 리뷰 후 확정)

## 기본 방향 (사용자와 합의한 아이디어)
- **기본 컨셉(2D 규칙)을 먼저 잡고, 3D는 제약·검증 레이어로 얹는다.** AI 딸깍으로 전부 맡기지 않음
  (같은 입력에 결과가 매번 달라지고, 물량 근거를 설명할 수 없음 → "사실/가정 분리, AI는 제안만" 원칙 유지).
- 배관팀이 PLOT·3D 모델을 계속 조금씩 바꿈 → 3D 파일을 받을 때마다 다시 계산해 **경로가 제대로 나오고, 겹치면 피하고, 단 쌓고, 서포트 반영**.

## 역할 나누기
| 누가 | 무엇을 |
|---|---|
| 프로그램 (결정적) | 3D 모델 → 배관·장비·철골 점유 격자 (EL 구간별) → 3D 경로 탐색 (하드 클래시 = 통과 불가, 이격거리 미만 = 비용↑) → 랙 위 빈 단 찾아 트레이 배치·단 쌓기 → 서포트 자리 클래시 확인·밀기 |
| AI (제안만, 사람 승인) | 좌표계 맞추기 (3d_protocol.md), 모델 객체 이름 → 배관/랙/장비 분류, 클래시 설명·수정안. 답은 정해진 JSON 형식(변경 제안 목록) |
| 사람 | 질문 카드 승인, 확정 구간 지정 |

## 리비전 대응
- 사용자 결정(JB 이동·경로 수정·트레이 크기·서포트 변경)을 **좌표 대신 장비 태그·랙·구간 기준**으로 저장 → 리비전이 와도 따라감 (지금은 좌표 기반이라 유실 가능).
- 리비전마다 **변경 대조표**: 움직인 장비, 바뀐 경로, 새 클래시, 물량 증감 (케이블·트레이·서포트).
- '확정' 찍은 구간은 클래시가 없는 한 유지.
- 흐름: 3D Rev N → 좌표 맞추기 (원점 그대로면 지난 변환 재사용 + 기준점 확인) → 점유 격자 → 다시 계산 → 클래시·증감 카드 → 검토 → 3D JSON 내보내기 → 모델에 얹기.

## 3D 리뷰용 데이터 (사용자 요청: 최대한 많은 정보를 프로퍼티로)
- **계장 레이어를 따로 구분**: 배관 모델과 섞이지 않게 레이어(그룹)를 나눔. 안: `INST` 아래 `INST_TRAY` (사다리·트렌치·Perforated), `INST_CABLE` (간선·분기), `INST_JB`, `INST_SUPPORT`, `INST_INSTRUMENT`, `INST_JOINT`, `INST_ROOM`. 추정 위치 계기는 `INST_INSTRUMENT_EST`로 따로.
- **모든 객체에 프로퍼티(userData / glTF extras)** 기록. 안:
  - 트레이: Tray No, 트렌치 줄 번호, 종류, 폭·단·높이, Fill, 길이, 탄 케이블 번호 목록, 서포트 번호 범위, 조인트, Unit
  - JB: JB No, 크기, 사용/스페어, 시스템·신호·IS, 재질·방폭·IP, 단자·글랜드, 멀티 번호·사양, 담긴 태그 목록, 자리(랙 기둥/장비)
  - 케이블: Cable No, 사양, 외경, 길이, From/To, 탄 트레이 순서, 산출 근거 문구
  - 계기: Tag No, Instrument Type, Service, System, I/O Type, P&ID No·Rev, Equipment No, JB·Field Cable·Multi, 위치 근거(추정 여부), 인덱스 Status
  - 서포트: Support No, 형식, 타피컬 번호, 역할(피팅·익스펜션), 고정(앵커·가이드), 폭·단, EL, 강재 kg
  - 공통: 프로젝트, 리비전, pid_io 버전, 만든 시각
- 형식 후보: 지금 JSON(pid_io-3d) 확장 + glTF/GLB(extras에 프로퍼티) 내보내기 → 배관팀 뷰어·Navisworks류에서 클릭하면 속성이 보이게.
- **사용자와 리뷰 후 확정** (항목·이름·레이어 규칙).

## 프롬프트
- 반복 작업은 버튼(프로그램)으로, 예외만 AI. 고정 프롬프트 세트를 `protocols/`에: 좌표 맞추기, 클래시 검토, 리비전 대조. 답 형식(JSON) 고정.

## 받아야 할 것 / 확인할 것
1. 3D 파일 형식 (three.js 장면 JSON / glTF·GLB / 기타)
2. 객체 이름·속성에 배관 라인 번호·사이즈, 랙 철골, 장비 태그가 있는지 (자동 분류 가능 여부)
3. 리비전 사이 원점·축척이 그대로인지
4. 앞으로 기준이 3D 모델인지 PLOT PDF인지
5. 이격 기준 (고온·수소 배관 등 mm)
6. 사용자가 말한 '변수'가 무엇인지
