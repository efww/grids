# pid_io 3D 데이터 맞추기 프로토콜 (pid_io-3d 0.2)

배관팀 three.js 모델 위에 pid_io가 만든 계장 데이터(계기·JB·케이블 경로·트레이·트렌치·서포트)를 얹을 때, 사람이나 다른 AI가 이 순서대로 따라 하면 됩니다.
파일: STEP 9 '3D 데이터 (JSON)' 버튼 → `projects/<프로젝트>/output/3D_<프로젝트>_<날짜>.json`

## 1. 파일 구조

| 키 | 내용 |
|---|---|
| `format`, `version` | `pid_io-3d`, `0.1`. 버전이 다르면 이 문서의 해당 버전을 볼 것 |
| `frame` | 좌표 기준: 원점, 축 방향, `m_per_pt`(축척), PLOT 파일 이름, 페이지 크기(pt) |
| `levels` | 높이 가정(설정값): 랙 최상단 EL, AG 서포트 EL, UG 깊이, 계기·JB·룸 인입 EL |
| `anchors` | 맞추기 기준점 후보: PLOT 장비 태그 위치, 제어실, IRP |
| `racks` | 랙 사각형(pt, m), 최상단 EL, 길이 방향 축 |
| `equipment` | PLOT PLAN 장비 태그 글자 위치 (장비 중심이 아니라 **글자 위치**) |
| `rooms` | 제어실(ROOM), IRP |
| `instruments` | 계기 태그, 위치, `src`(위치 근거), `estimated`(추정 여부), 연결 JB |
| `jbs` | JB 번호, 위치, 크기, 종류, 시스템·신호, 사양(재질·방폭·IP) |
| `cables` | 케이블 번호, 사양, 외경(mm), 길이, `path`(3D 꺾임점 목록), 탄 트레이 번호 |
| `trays` | 트레이·트렌치 구간 (트렌치는 `run` = 트렌치 한 줄 번호, 폭·단): 종류(`ladder_on_rack` / `ladder_on_supports` / `ug_trench`), 시작·끝 점, 폭·단 수, Fill, 옆 트레이와의 간격 |
| `supports` | 서포트 번호, 형식(L/T/H/RT/RF/RC/UB/UM/UP), 타피컬 번호, 바닥 점, 최상단 EL, 역할(피팅·익스펜션), 고정(앵커·가이드), `blocked`(장비 안) |
| `joints` | 익스펜션 스플라이스 조인트 (0.2): 번호, 구간, 위치, 트레이 |
| `perforated` | JB → 계기 Perforated 트레이 (태그별), 길이, 브래킷 수, 경로 |
| `counts` | 개수 요약 (`instruments_estimated` = 위치가 추정인 계기 수) |

모든 점은 `{"pt": [x, y], "m": [x, y, z]}` 두 가지로 줍니다.

## 2. 좌표

- 원점: PLOT PLAN PDF 1쪽 **왼쪽 위 모서리**.
- `x`: 도면 오른쪽 (+). `y`: 도면 **아래쪽** (+, PDF 좌표). 북쪽이 위라면 북쪽은 −y.
- `m = pt × m_per_pt`. `z` = 지반(GL) 기준 높이 EL(m), UG는 음수.
- three.js (Y가 위): `X = m[0]`, `Y = m[2]`, `Z = m[1]`. 오른손 좌표계, 위에서 본 도면과 같은 방향.
- **높이는 설정값**입니다 (측량값 아님). 랙 EL·계기 EL은 모델에서 실제 값을 읽어 `levels`와 비교하세요.

## 3. 맞추는 순서

1. **단위 확인**: 모델 단위가 mm이면 ×1000. 모델에 축척을 모르면 아래 2번의 두 점 거리 비로 구함.
2. **기준점 2~3개 대응**: `anchors`에서 모델에도 있는 장비를 2개 이상 고릅니다 (서로 멀리 떨어진 것, 가능하면 3개).
   - 주의: `equipment`는 **태그 글자 위치**라 장비 중심과 수 m 다를 수 있음. 모델의 장비 중심을 쓰되 오차 허용 3~5 m.
   - 제어실(ROOM)도 좋은 기준점.
3. **2D 변환 구하기** (위에서 본 평면만): 대응점으로 회전 θ + 이동 (tx, ty) (+ 필요하면 축척 s)를 최소제곱으로 구합니다.
   `[X, Z]_model = s · R(θ) · [x_m, y_m] + [tx, tz]`. 모델 북쪽이 +Z가 아니면 y 부호를 바꾼 뒤 다시.
4. **높이 맞추기**: 모델 GL(지반) 높이 `Y0`를 찾아 `Y_model = Y0 + z`. 랙이 모델에 있으면 랙 최상단 높이를 읽어 `levels.rack_top_el`과 다르면 트레이·케이블 z를 그만큼 옮김.
5. **검증**:
   - `racks` 사각형이 모델 파이프랙과 겹치는지 (중심선 오차 < 랙 폭/2).
   - `trays` 중 `ladder_on_rack`이 랙 위에 있는지.
   - 대응에 안 쓴 장비 몇 개로 오차 확인 (< 5 m면 통과, 큰 오차는 기준점 다시 고르기).
6. **표시 권장**: 추정 계기(`estimated: true`)는 다른 색/반투명. `trays`는 폭(mm)×높이(mm) 박스, 단 수만큼 `levels`의 단 간격(약 300 mm)으로 쌓기, 같은 구간의 여러 트레이는 옆으로 나란히: `side_offset_mm` = 그 구간 첫 트레이 가장자리에서 이 트레이 가까운 가장자리까지 (앞 트레이 폭 + 100 mm 누적, v13). 케이블은 `path` 꺾임점을 잇는 선(외경 `od_mm`).

## 4. 이름 규칙

- 계기 `10-PT-0602`, JB `JB-<유닛>-<시스템><신호>[I]-<순번>`, 멀티 `MC-…`, 분기 `C-<태그>`, 광 `FO-…`
- 트레이 `TR-<유닛>-<순번>[-C 통신 / -I IS]`, 트렌치 `UG-<유닛>-<순번>`, Perforated `PT-<유닛>-<순번>`
- 서포트 `SP-<유닛>-<순번>` (L/T/H/랙 위 T), 클램프 지점 `CL-`, 트렌치 브래킷 `UB-`, 직매설 표지 `UM-`, 풀 피트 `UP-`

## 5. 안 맞을 때 확인할 것

| 증상 | 원인 후보 |
|---|---|
| 전체가 위아래로 뒤집힘 | y 축 방향 (PDF는 아래가 +). y 부호 바꾸기 |
| 크기가 몇 배 다름 | 단위(mm/m) 또는 `m_per_pt` 축척 (STEP 6 축척 카드 확인) |
| 일부 계기만 엉뚱한 곳 | `estimated: true` = P&ID 시트 장비 평균 위치. 원래 한계 |
| 트레이가 랙 옆을 지나감 | 그 구간 랙이 자동 인식 안 됨 (STEP 6에서 랙 그리기) |
| 높이가 다 다름 | `levels`는 설정값. 모델 랙 EL로 다시 맞추기 |

## 6. 다른 AI에게 시킬 때 프롬프트 예

> 첨부한 pid_io-3d JSON(0.2)과 three.js 장면을 맞춰 줘. `protocols/3d_protocol.md` 3절 순서대로: anchors 중 모델에도 있는 장비 3개를 골라 평면 변환(회전·이동·축척)을 최소제곱으로 구하고, 모델 GL 높이로 z를 옮긴 뒤, 대응에 안 쓴 장비로 오차를 표로 보여 줘. 변환 행렬과 오차표만 답하고, 데이터 값은 바꾸지 마.

## 7. 확인용 3D 보기

앱 STEP 9 '3D 보기' 버튼 (`/viewer3d?p=<프로젝트>`): 인터넷 없이 three.js(앱 폴더 `pid_io/app/static/vendor/three`, MIT)로 PLOT PLAN을 바닥에 깔고 같은 데이터를 그립니다. 배관 모델에 얹기 전에 우리 데이터가 맞는지 눈으로 보는 용도.

## 8. 보강 모델 배치 규칙 (v13.1) · AI 3D 리뷰

- 랙 위 트레이: **같은 방향** 모델 랙에 붙이고, 그 랙의 케이블 단 EL. 랙 하나 위 모든 계장 트레이는 폭 큰 것부터 차선 끝(설정 `tw_lane`, 여유 `tw_margin`)에서 안쪽으로 자리 배정, 서로 0.1 m 간격 (길이 방향 0.5 m 넘게 겹칠 때만 같은 자리 불가).
- 케이블 경로: 경사 마디 없음 - 낮은 EL로 수평, 그다음 수직 라이저.
- 다른 공종과 충돌: 계장이 옆(차선) → 위(`tw_step`씩, 최대 `tw_max_up`)로 비킴. 기록 `clash_moves.json`.
- 리뷰: 세트 폴더 `3D_REVIEW_PROMPT.md` + `3D_REVIEW_PRECHECK.csv` + `3D_REVIEW_ANSWER_SCHEMA.json` (규칙 V01~V09는 `pid_io/review3d.py`). 회사 AI 답은 STEP 10 '4. AI 3D 리뷰'에 붙여 넣기.
