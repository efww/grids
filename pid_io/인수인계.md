## 4. 핵심 설계 원칙 (바꾸지 말 것)

1. **사실과 가정 분리**: 도면 인식은 항상 전부, IO를 바꾸는 건 체크리스트뿐. 케이블도 같음: 인덱스 = 사실, 케이블 설정 = 가정, 케이블 행마다 근거 열.
2. **IO 1점 = 인덱스 1행**. 산출구분 7종 (도면인식 / Typical파생 / 트레인복제 / 대수복제 / 장비Typical / 패키지 / 스페어).
3. Typical은 체크리스트 `Typical_Points` 시트가 단일 정의.
4. **AI·자동 추정은 제안만**, 사람이 승인·수정.
5. 오프라인 우선.

## 6. 케이블 모듈 (STEP 6 '케이블 · JB', 메뉴 파란색 '확장')

**설정** (프로젝트별 `cable.json`, 프리셋 `<HOME>/_cable_presets/*.json` = 리드 엔지니어 기준). 저장값이 선택지에서 사라지면 기본값으로 복귀.

| 탭 | 주요 기본값 |
|---|---|
| IO별 케이블 | AI·AO·DI 1P×1.25SQ OS, **DO 2C×2.0SQ** (DI와 같은 JB), RTD 1T×1.25SQ. 패키지 PLC 통신 **광케이블** FO 12C SM Armoured, **통신 이중화**(포트마다 1가닥 / 단일=패키지당 1가닥), RS-485(MCC 통신) |
| JB · 멀티 | JB 24P/24P/12T, 스페어 20% (사용 × 1.2 ≤ JB 크기), 멀티 = JB 크기, 1.25SQ, 아날로그 IS+OS |
| JB 분리 기준 | 유닛별, 시스템 분리 ON, 아날로그/디지털 분리 ON, DO 별도 OFF, RTD 별도 ON, IS 전부 Non-IS, 패키지 인터페이스 = 제어반(UCP)→룸 직결, 경계 안 계기 = Skid JB, **MCC 신호 출발점 = IRP** (MCC↔IRP는 전기 범위, 미집계) |
| 경로 · 높이 (Z) | PLOT 좌표 사용 ON, 간선 랙(AG), 랙 EL 6m, 랙 없는 구간 AG 서포트 3m (또는 UG 0.8m), 계기 1.5m / JB 1.2m / 룸 인입 0m, 랙 우선도 3, 직접 그린 랙 폭 6m, 분기 우회계수 1.1, 분기 최소 5m, **JB 반경 40m** |
| 길이 가정 | PLOT 없거나 위치 못 찾을 때: 계기→JB 30m, JB→룸 200m(유닛별 값), IRP→룸 50m, 여유 10%, 5m 올림, 도착 룸 CCR |
| PLOT PLAN 초안 | 7절 |

**경로 규칙 (`cable.classify`)**
- 필드 계기 → 분기 → 필드 JB → 멀티 → 룸. PLOT이 있으면 JB는 **JB 반경 안 계기끼리 공간 클러스터**, JB 위치 = 계기 중심.
- 패키지 Typical 행(`symbol_cls == PACKAGE`, 트레인 복제 포함) → 제어반→룸 멀티 (패키지·시스템·신호별).
- 벤더 경계 안 도면 계기 → Skid JB. MCC 행 → IRP→룸 멀티페어 집합(또는 모터당 멀티코어). 통신 포트 → 광/RS-485 직결.
- 케이블 없음: 스페어, 소프트 태그, IO 없음, PKG PLC IO, 룸 안 계기 (사유별 행 수 표시).

**패키지 타입 → 케이블** (체크리스트 C01 / 패키지별 연결 방식): 전부 하드와이어 = DI/DO 멀티 + 경계 안 계기 Skid JB, 벤더PLC+통신 = 광케이블만, 혼합 = 멀티 + 광.

**출력** `output/Cable_Schedule_*.xlsx`: Cable_Summary(사양별 물량, JB 크기, 케이블 없는 행), Cable_Schedule(Cable No, From/To와 종류, 사양, 길이, Unit, P&ID, 좌표, 근거), JB_List(JB별 채움·태그), Cable_Settings.

## 7. PLOT PLAN (`plot.py`, STEP 6 'PLOT PLAN 초안' 탭)

- **업로드**: PLOT PLAN(벡터 PDF) + 축척 참고 도면(선택). `input/`, 읽은 결과 `cache/plot.json`(파일 버전 키 v2), 그림 `cache/plot_50.png`, 사용자 수정 `plot_decisions.json`(room, irp, m_per_pt, confirmed, racks_add, racks_off, routes_edit). 새 PLOT 업로드 시 수정값 초기화.
- **축척 판정 순서**: ① 타이틀 블록 '1:N' ② 치수 문자 + 보조선 간격(2개 이상 일치, 글리프 획 5pt 미만 무시) ③ 축척 있는 참고 도면과 같은 장비 외곽 크기 비 ④ 질문(1:N 입력).
- **장비 위치**: 태그 글자 좌표(`_keys`: A/B 분리, PKG=PK, 패키지 번호 뒤 숫자 제거). 같은 태그가 여러 번 그려지면 읽는 순서로 유닛 배정('추정').
- **계기 위치**: Equipment No / 패키지 / 원본 태그 → 그 P&ID 시트에 적힌 장비들의 중심(트레인 접두 치환) → 유닛 장비 중심 → 미정.
- **제어실·IRP**: 'CCR/MCB/CONTROL', 'IRP/MCC' 글자. 질문 카드 '맞음' / '도면에서 위치 지정'(클릭).
- **파이프랙 인식** (`detect_racks`): 위에서 본 사다리. 기둥 표시(0.5~1.6m 사각, 안에 H형강) 두 줄, 줄 간격 3~12m, 베이 ≤13m, 3베이·10m 이상.
- **장애물** (`detect_obstacles`): 2~80m 사각(안에 글자·도형 8점 이상) + 둥근 탱크 외곽. 공간 버킷으로 0.4초.
- **경로** (`Router`): 1m 격자, 랙 1/m, 랙 밖 '랙 우선도'/m, 장애물 통과 불가. 제어실에서 Dijkstra 한 번(0.1초). 건물 안 출발점은 가장 가까운 빈 칸에서. 높이 = 랙 구간 랙 EL, 랙 밖 AG/UG, 오르내림 횟수만큼 더함.
- **수정**: 랙 그리기(다각선, 축 방향) / 랙 끄기·켜기 / 그린 랙 ✕. **경로 선 클릭 → 꺾임점 끌기·더블클릭 추가/삭제**, 가로·세로로만 스냅(`orthogonal`), 놓으면 케이블 스케줄 즉시 반영, 근거 '사용자 수정 경로', '자동 경로로 되돌리기'. 경로 이름(rid) = JB 번호 / 'PKG <패키지>' / 'IRP' / 'COMM <출발>'.

- 내보낼 데이터 (초안): 계기(태그, x·y·z, 위치 근거·추정 여부), JB(번호, 자리, x·y·z, 크기·사양), 케이블(번호, 사양, 외경, 경로 꺾임점 x·y·z), 트레이·트렌치 구간(번호, 종류, 폭·단, 시작·끝 x·y·z, EL), 랙(사각형, EL), 제어실·IRP. 좌표는 PLOT pt와 m 둘 다, 원점·축척·축 방향을 파일 머리에 명시.
- 형식 후보: JSON (three.js에서 바로 읽기) + 같은 내용 엑셀. 프로토콜 문서: 좌표 맞추는 순서(기준점 2~3개 대응), 단위, 높이 기준(EL vs 모델 Y), 이름 규칙, 실패할 때 확인할 것.
