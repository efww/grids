현대하모니 글꼴 넣는 곳
- PC에 현대하모니가 설치되어 있으면(C:\Windows\Fonts 또는 사용자 글꼴 폴더) 자동으로 찾으므로 넣지 않아도 됩니다.
- 설치가 안 된 PC면 이 폴더에 현대하모니 L(본문), B 또는 M(굵게) 파일(.ttf/.otf/.woff2)을 넣고 실행.bat을 다시 실행하세요.
- 파일 이름에 'Harmony' 또는 '하모니'가 들어가야 하고, 이름 끝 L/M/B로 굵기를 구분합니다. 예) HyundaiHarmonyL.ttf
- 화면 왼쪽 아래에 '글꼴: 현대하모니 L ✓'가 보이면 적용된 것입니다.
