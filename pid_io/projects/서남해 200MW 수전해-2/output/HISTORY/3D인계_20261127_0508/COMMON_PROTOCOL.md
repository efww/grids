# pid_io 계장 개념설계 공통 프로토콜 v1.0

범위: 어떤 개념설계에든 쓰는 공통 부분만 (태그 번호·프로젝트 이름·프로젝트 값 없음)

## 규칙

- **P01** 같은 팩트(도면·PLOT·3D) + 같은 체크리스트 값 = 같은 물량. 결과는 매번 다시 계산하고 사람이 손으로 고치지 않는다.
- **P02** 우선순위: 사람 결정 > 3D 팩트 > PLOT 자동 인식 > 체크리스트 기본값. 3D는 사람 결정을 바꾸지 않는다.
- **P03** 물량이 바뀌는 3D 반영은 제안 → 미리보기(숫자·JB·PLOT 마크업) → 사람 승인 순서로만 반영한다.
- **P04** 계장은 랙의 계장 차선을 먼저 쓰고, 다른 공종과 부딪히면 계장이 옆 → 위 순서로 비킨다.
- **P05** 랙 위 트레이는 같은 방향 랙의 케이블 단 EL에, 한 랙 위 트레이끼리는 겹치지 않게 자리 배정한다.
- **P06** 케이블 경로에 경사 마디를 두지 않는다 (수평 + 수직 라이저).
- **P07** JB는 장비·랙 안에 두지 않는다 (랙 기둥 바깥, 장비 가장자리).
- **P08** 3D 점검 규칙 V01~V09를 통과하지 못한 항목은 HOLD로 두고 사람이 판단한다.
- **P09** 출력은 LATEST(하나) / ISSUED(발행 고정) / HISTORY(안 지움), 모든 엑셀에 지문.
- **P10** AI는 제안·해석만 하고, 값의 반영과 공통 규칙 승격은 사람이 승인한다.
